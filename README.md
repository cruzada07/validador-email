# Validador de Email

Aplicación web sencilla para validar direcciones de correo electrónico mediante HTML, CSS y JavaScript.

## Descripción

Este proyecto consiste en un validador de correos electrónicos desarrollado utilizando tecnologías web básicas.

El usuario puede ingresar una dirección de correo y la aplicación verifica si cumple con un formato válido. El objetivo principal del proyecto es practicar la manipulación del DOM, el uso de eventos y la implementación de lógica de validación mediante JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
